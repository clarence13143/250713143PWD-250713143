BEASISWA UAJY

UAJY menyelenggarakan berbagai program mBEASISWA dengan kriteria dan manfaat yang berbeda beda.

  • Beasiswa Program Sarjana (S1) yaitu Program Seleksi Siswa Berprestasi (PSSB), Beasiswa Program Internasional (BPI), Beasiswa Program Akademik (BPA), dan lain-lain.
  • Beasiswa Program Pascasarjana (S2), yaitu Beasiswa Prestasi Magister (BPM), Beasiswa Magister Unggul (BMU), dan BIMA.
  • Beasiswa Prestasi EP Unggul (BEPU).
